# NISHETA eSPORTS HUB

Phase 1: каркас сайта, 11 профилей игроков, дашборд-заглушка. Данные Dota подключаются в Phase 2.

## Деплой с телефона (пошагово)

### 1. Загрузить код в свой GitHub-репозиторий
Открой репозиторий `nisheta-esports-hub` на github.com → кнопка **Code** → вкладка **Codespaces** → **Create codespace on main**. Откроется редактор кода прямо в браузере.

Открой терминал внутри Codespace (значок терминала снизу) и вставь содержимое файла `setup.sh` целиком (я приложил его отдельным файлом). После вставки нажми Enter — он создаст все файлы проекта.

Затем в том же терминале:
```
git add .
git commit -m "Phase 1: каркас проекта"
git push
```

### 2. Подключить Neon (база данных)
Зайди в neon.tech → открой свой проект → вкладка **Connection Details** → скопируй строку, которая начинается на `postgresql://`.

### 3. Подключить Vercel
Зайди в vercel.com → **Add New → Project** → выбери репозиторий `nisheta-esports-hub` → **Import**.
В разделе **Environment Variables** добавь:
- `DATABASE_URL` — строка, скопированная из Neon.

Нажми **Deploy**.

### 4. Создать таблицы и заполнить 11 игроков
Проще всего — снова через Codespaces:
```
npm install
npm run db:push
npm run db:seed
```
Первая команда поставит зависимости, вторая создаст таблицы в Neon по схеме, третья — заполнит 11 игроков.

После этого зайди по ссылке, которую даст Vercel (`nisheta-esports-hub.vercel.app`) — увидишь дашборд и список игроков.

## Лобби: новые возможности

В актуальной версии лобби поддерживает:
- роспуск активного лобби;
- замену игрока внутри существующего слота;
- распределение 5 позиций;
- рандомизацию героев с учётом позиции и статистики OpenDota;
- запрет повторного героя внутри одного лобби;
- просмотр популярных предметов героя по стадиям игры через OpenDota.

Для роспуска/замены в текущей версии не используется авторизация, поэтому эти действия доступны участникам, имеющим доступ к странице лобби.
